# JavaScript TODO App

## About
A simple TODO application built using HTML, CSS, and JavaScript. It helps users manage tasks through a simple and interactive interface.

## Features
- Add new tasks.
- Display tasks in a list.
- Delete individual tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a task and click **Add Task**.

## Learning Outcomes
- Handling button click events.
- Manipulating DOM elements.
- Updating webpage content dynamically.
- Organizing HTML, CSS, and JavaScript files.
